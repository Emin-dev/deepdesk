## Recommended minimal packaging approach

Preserve the exact official standalone CPython tree and every reviewed installed wheel payload. Place them inside `DeepdeskEngine.app/Contents/Resources/Python`; use a small first-party compiled relative launcher at `Contents/MacOS/DeepdeskEngine`. Keep `engine_entry.py` at a fixed Resources path and launch only the bundled interpreter with `-I -B` and that fixed wrapper. The launcher must resolve its own real executable location independently of cwd, reject missing/escaping targets, accept only the existing empty argument list or `--self-test`, preserve the owned PID with exec, and scrub externally supplied interpreter/dyld injection controls. It must never use PATH, a system Python, a shell, a venv redirect or an executable selected by environment.

The interpreter archive is the already tested CPython 3.12.15+20261009 aarch64 install-only archive, SHA-256 `83dcb04777c798bd95f3687acf9ae84b09860272ee6bdfb05be8bcf9447f75b8`. Preserve its relative symlinks/layout. Install the complete reviewed wheel lock directly into the staged standalone prefix, not into a venv later copied elsewhere. Do not prune modules, providers, search engines, resources or distribution metadata to make collection easier. Isolated Python still processes site .pth files: preserve the reviewed exact setuptools startup-file allowlist and reject new executable startup files. Inventory generated console-script shebangs; never accidentally execute absolute staging-path scripts, and explicitly normalize any required bundled command under its own file transformation manifest. Initially retaining reviewed build tools is preferable to an unreviewed dependency-pruning change; subsequent minimization can be separately proved.

This replaces the draft PyInstaller mechanism, not the upstream engine. It avoids collection omissions and executing third-party PyInstaller hooks. The draft freeze has a concrete hook-name collision: Patchright advertises hooks named for Playwright. Neither existing draft freeze nor its provenance flag should be repurposed silently. A new bundle-specific receipt, input manifest, scripts and branch would need independent exact review.

Maintain the native contract `Deepdesk.app/Contents/Helpers/DeepdeskEngine.app/Contents/MacOS/DeepdeskEngine`. Preserve native catalog resources separately: `Contents/Resources/Deepdesk_Deepdesk.bundle` and full Python catalog `Contents/Resources/curated-model-catalog.json`. Inference runtime/model downloads are outside this engine-only candidate.
