# Deepdesk security status

Deepdesk is an early-stage, independent source-copy project. The native macOS application has not yet completed build, runtime, signing or notarization verification. Do not treat this source snapshot as a production-ready security release.

Do not post API keys, passwords, private research, personal files or exploitable vulnerability details in public issues. A Deepdesk private disclosure process and response targets have not yet been established; arrange a private channel with the maintainer before sending sensitive details. No response-time commitment is made by this initial import.

The inherited engine's original security policy is retained in [docs/upstream/SECURITY.md](docs/upstream/SECURITY.md) as reference. Its contacts, timelines and security claims belong to the upstream project, and do not establish Deepdesk guarantees. If a finding is confirmed to affect unchanged upstream code, use the upstream project's own current reporting guidance.

The imported automation is inactive. Dependencies and setup scripts have not been installed or executed during import. Credentials, provider configuration, paid model/search integrations, signing and publishing require separate setup and review.
